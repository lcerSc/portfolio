Portfolio

This repository contains a Streamlit portfolio app. The app is a Python application and cannot run directly on GitHub Pages.

What was added:

  • CI workflow (syntax check)
  • Docker publish workflow to GitHub Container Registry (GHCR)
  • GitHub Pages deploy workflow (publishes this docs folder)

To run the app locally:

venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py

To deploy the app you can:

  • Use Streamlit Cloud and connect this repository
  • Use the Docker image published to GHCR to deploy to a container host
